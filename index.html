Lockout.

In a factory, a machine can't be switched on until every worker has taken their own padlock off the switch, and nobody may remove someone else's lock. A grad school application works the same way: 5 of its 7 locks belong to someone else. This lock screen shows whose key you're waiting on, tells you when to nudge them, and flips the switch to ON when the last lock comes off.

How it works

1 One switch

Your application is a switch held at OFF. It only flips to ON (complete) when every padlock is off the lockout bar: the real rule from OSHA's lockout/tagout standard (29 CFR 1910.147), where each worker removes only their own lock.

2 One lock per keyholder

Every milestone is a padlock with a tag. Red: their key (recommenders, the registrar, ETS). Yellow: your key. You can't take someone else's lock off, so their locks start first and get nudge days.

3 A new frame every day

Rubber stamps track each lock (ordered, invited, nudged ×2), today's lock gets a TODAY tape, a lock reads DUE TODAY on its date and OVERDUE after it, and comes off only when you enter the day its key came back. The switch turns ON after you submit.

The plan (worked out with Gemini)

Due dates and daily tasks come from Gemini's plan. The Back column is one sample run, so the frames can show keys coming back early: the locks started first came back first.

Hang your own locks

Up to 7 locks. Stamps are dated words that show on the tag the day after, like 11/21 ASKED, 11/30 NUDGED. Keep names short (they print big): LEE, REGISTRAR.

The whole plan lives in the link, so you can bookmark it or send it to a friend. Nothing is stored anywhere else.

Change it every morning (iPhone)

  1. Download Every day (.zip), unzip it, and put the Lockout folder in iCloud Drive/Shortcuts.
  2. Shortcuts → Automation → New → Time of Day, 6:00 AM, Daily, Run Immediately.
  3. Actions: Current Date → Format Date (custom yyyy-MM-dd) → Get File Lockout/[Formatted Date].png → Set Wallpaper Photo (Lock Screen).
  4. Settings → Notifications → Display As: Count, so notifications don't cover the tags.

On Android, set the day's PNG by hand, or use an automation app that changes the wallpaper on a schedule.
